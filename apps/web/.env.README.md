# Environment Configuration

Copy this file to `.env.local` and fill in your actual values.

```env
# Authentication (Clerk)
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_your_key_here
CLERK_SECRET_KEY=sk_test_your_key_here

# AI Configuration
OPENAI_API_KEY=sk-your_openai_key_here

# Optional: Override default AI model (default: gpt-4o-mini)
OPENAI_DEFAULT_MODEL=gpt-4o-mini
```

## Getting API Keys

1. **Clerk**: Sign up at https://clerk.com
2. **OpenAI**: Sign up at https://platform.openai.com

## Verification

After creating `.env.local`, run:
```bash
pnpm dev --filter=web
```

The app will throw a clear error if any required keys are missing.
